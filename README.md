# 📘 Справочник ошибок компилятора Clever
## Small Basic Plus — для юных программистов
📘 Справочник ошибок компилятора Clever (Small Basic Plus) для юных программистов. 161 ошибка с переводом, объяснением и примерами исправления. Для уроков, кружков и самостоятельного изучения.

![Версия](https://img.shields.io/badge/версия-1.0-green)
![Статус](https://img.shields.io/badge/статус-в_процессе_наполнения-yellow)
![Ошибок](https://img.shields.io/badge/ошибок-161-red)

## 📖 Как пользоваться справочником

1. **Прочитай сообщение об ошибке** в окошке Clever.  
2. **Найди номер ошибки** в этом справочнике.  
3. **Прочитай объяснение** — там написано простыми словами, что случилось.  
4. **Посмотри пример** — там показано, как выглядит НЕПРАВИЛЬНЫЙ код и ПРАВИЛЬНЫЙ код.  
5. **Исправь свою программу** по образцу.

---

### ⚙️ Если ошибка №1–№5 (компиляторные):

1. Открой папку с твоей программой (файл `.bp`).  
2. Найди там **временную папку** с именем `~имя_твоей_программы` (например, `~robot`).  
3. Зайди в неё и открой файл с именем `~имя_твоей_программы.bp` в Блокноте или любом другом текстовом редакторе.  
4. Найди строку и позицию, которую указал компилятор (например, `123:45`).  
5. Посмотри на код в этом месте — именно здесь ошибка!  
6. Вернись в свой исходный файл (`.bp`) и исправь ошибку в том же месте.

## ⚙️ БЛОК 0: ОШИБКИ КОМПИЛЯТОРА (№1–№5)

Эти ошибки возникают **после работы препроцессора**. Номера строк в них **не совпадают** с вашим файлом `.bp`!

### Алгоритм решения для всех ошибок этого блока:
1. Открой папку с программой.  
2. Найди папку `~имя_программы`.  
3. Открой файл `~имя_программы.bp` в Блокноте.  
4. Найди строку и позицию (например, `123:45`).  
5. Посмотри на код — ошибка там!  
6. Вернись в свой `.bp` файл и исправь.

---

### Ошибка №1: Unexpected Symbol

**Что пишет компьютер (по-английски):**
```
Unexpected Symbol at 123:45
```

**Что это значит простыми словами:**  
Компилятор встретил символ, который не может быть использован в этом месте (например, `@`, `#`, `$` или лишняя запятая).

**Как исправить:**  
1. Проверь, нет ли в строке лишних символов.  
2. Убедись, что все запятые и точки расставлены правильно.  
3. Проверь, не используешь ли ты кириллицу в именах переменных.

**Неправильно:**
```
x = 5 @ 3
```

**Правильно:**
```
x = 5 + 3
```

---

### Ошибка №2: Unexpected ID

**Что пишет компьютер (по-английски):**
```
Unexpected ID at 123:45
```

**Что это значит простыми словами:**  
Компилятор встретил идентификатор (имя переменной, метки или команды) там, где его не ожидал. Часто — забыт оператор или ключевое слово (`Then`, `To`).

**Как исправить:**  
1. Проверь, не забыл ли ты `Then` в `If`.  
2. Проверь, не забыл ли ты `To` в `For`.  
3. Проверь, не стоит ли имя переменной рядом с числом без оператора.

**Неправильно:**
```
x = 5 3
```

**Правильно:**
```
x = 5 + 3
```

---

### Ошибка №3: Unexpected EOL

**Что пишет компьютер (по-английски):**
```
Unexpected EOL at 123:45
```

**Что это значит простыми словами:**  
Компилятор ожидал продолжение строки (например, закрывающую кавычку или скобку), но встретил конец строки.

**Как исправить:**  
1. Проверь, все ли кавычки закрыты.  
2. Проверь, все ли скобки стоят парами.  
3. Проверь, не обрывается ли строка на операторе.

**Неправильно:**
```
TextWindow.WriteLine("Привет
```

**Правильно:**
```
TextWindow.WriteLine("Привет")
```

### Ошибка №4: Expected Expression

**Что пишет компьютер (по-английски):**
```
Expected Expression at 123:45
```

**Что это значит простыми словами:**  
Компилятор ожидал выражение (число, переменную, вызов метода), но вместо этого ничего не нашёл.

**Как исправить:**  
1. Проверь, есть ли что-то после `=`.  
2. Проверь, есть ли операнды у операторов.

**Неправильно:**
```
x = 5 +
```

**Правильно:**
```

```

### Ошибка №5: Expected Statement

**Что пишет компьютер (по-английски):**
```
Expected Statement at 123:45
```

**Что это значит простыми словами:**  
Компилятор ожидал команду (Statement), но встретил что-то другое. Часто — пустая строка или незаконченная конструкция.

**Как исправить:**  
1. Проверь, есть ли команда после `Then`.
